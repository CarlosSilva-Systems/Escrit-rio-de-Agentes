## B. Cobrança e statusLine
- [F] **A premissa do pedido (crédito separado do Agent SDK) está desatualizada.** A mudança foi **pausada em 15/06/2026**; com login por plano, `claude -p` e Agent SDK **continuam no mesmo limite 5h/7d** do modo interativo (support.claude.com "Use the Claude Agent SDK with your Claude plan", atualizações 15/06 e 07/10/2026). Existem "monthly API credits" (Max US$100, Ultra US$200, Team em pool; **Pro não elegível**), mas só valem com **chave de API**, não com login por plano nem Desktop. Quando acabam, as requisições param (não cobra do plano).
- Implicação: no plano de assinatura, interativo (pty) x `-p` **não muda de onde sai o consumo**. O modo "Automático" (`-p` + stream-json) é seguro em custo e muito mais simples/robusto que raspar uma TUI via ConPTY. Manter o modo como configuração (flag), pois a Anthropic pode retomar a separação. Incertezas: páginas datadas só como "updated over a week ago"; fontes secundárias divergem → Carlos deve conferir `/usage` e claude.ai/settings/usage.
- [F] Termos (code.claude.com/docs/en/legal-and-compliance): limites assumem "ordinary, individual usage"; proibido a terceiros rotear requisições por credenciais de plano de usuários; permitido o próprio usuário logar no binário oficial sem modificação. Nenhuma regra explícita sobre automatizar o `claude` interativo via pty (ausência de regra ≠ permissão). Painel local do próprio Carlos com binário oficial está no espírito dos termos [I] (não é parecer jurídico). **Não ler nem usar o token OAuth.**
- [F] statusLine: stdin JSON com `rate_limits.five_hour` / `seven_day` {`used_percentage` 0–100, `resets_at` epoch s} (Pro/Max/Ultra, só após 1ª resposta da API; cada janela pode faltar e some após o reset). `spend_limit` só atrás de gateway. **Não há janela por modelo.** Também: `session_id`, `transcript_path`, `model`, `cost`, `context_window`, `workspace`, `agent`. Atualiza a cada mensagem do assistente (debounce 300ms), `refreshInterval` opcional; timeout numérico não documentado; saída só se exit 0; exige workspace trust; no Windows roda via Git Bash ou PowerShell, use `/` no caminho.

Medidor funciona com sessões CLI/pty/`-p`; [?] `-p` pode não executar statusLine. Teste de 2 min proposto (log de stdin). Desenho: "último valor conhecido + atualizado há X min".

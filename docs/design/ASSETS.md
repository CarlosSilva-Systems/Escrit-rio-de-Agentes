Observações importantes
1. **Modern Interiors (LimeZu)** é o pacote que melhor combina com o pedido (escritório moderno, 16×16, personagens modulares com gerador). Mas a licença **proíbe distribuir os arquivos**. Se o repositório for **público**, os PNGs **não podem ficar no Git**; o repositório só teria código + um passo "coloque seu pacote comprado em `assets-private/`". Se for **privado**, não há conflito. Recomendo escrever ao autor perguntando se "repositório público com os sprites processados" é aceito (o texto da página não cobre).
2. Não achei **nenhum pacote CC0 com pets** que sirva (Pomerânia laranja e golden filhote). Os pets de shubibubi são Yorkie e gato (não servem) e são pagos. **Os dois mascotes serão desenhados do zero** em qualquer combinação.
3. O tamanho exato de quadro dos personagens do Modern Interiors e do Metro City **não aparece nas páginas** [?]; o pedido fala em 16×32 (e o Pixel Agents usava Metro City). Validar baixando a versão grátis/CC0 antes de decidir.
4. Kenney Roguelike Indoors: a página não informa o tamanho do tile [?] (a série costuma ser 16×16; **validar**). O visual é de RPG/casas, não de escritório moderno: serve de base de piso/parede/plantas/mobília simples, mas faltam monitores, servidores, fliperama etc.
